======================================================================

AIM:
To implement informed (heuristic) search technique using A* Algorithm to solve the Water Jug Problem

RESOURCE REQUIREMENTS:
Windows, Python 3.8 or Higher, Google Colab

THEORY:
An Informed Search (also called Heuristic Search) is a search technique that uses additional knowledge, called a heuristic, to guide the search toward the goal. It explores the most promising states first, making it faster and more efficient than uninformed search techniques.

A* Search is one of the most widely used informed search algorithms. It combines:
• g(n) = Actual cost from the start node to the current node.
• h(n) = Estimated cost from the current node to the goal.

The evaluation function is:
f(n) = g(n) + h(n)

where:
• f(n) = Total estimated cost
• g(n) = Actual path cost
• h(n) = Heuristic estimate

The algorithm always selects the node with the smallest f(n) value.

Water Jug Problem
Two water jugs are given:
• Jug A = 4 liters
• Jug B = 3 liters
Initially, both jugs are empty.
Allowed operations:
1. Fill Jug A
2. Fill Jug B
3. Empty Jug A
4. Empty Jug B
5. Pour water from Jug A to Jug B
6. Pour water from Jug B to Jug A

Goal: Measure exactly 2 liters in the 4-liter jug.

Initial State:
(0,0)

Goal State:
(2,x)
where x can be any quantity.

ALGORITHM:
1. Start from the initial state (0,0).
2. Insert the initial state into a priority queue.
3. Calculate the heuristic value.
4. Generate all possible neighbors states.
5. Compute:
   o g(n) = Actual cost
   o h(n) = Heuristic cost
   o f(n) = g(n) + h(n)
6. Select the state having the smallest f(n).
7. Repeat until the goal state is reached.
8. Print the solution path.

CONCLUSION:
The Water Jug Problem was successfully solved using the A (A-Star) informed search algorithm.
