EXPERIMENT NO-4
======================================================================

AIM:
To implement alpha beta pruning

RESOURCE REQUIREMENTS:
Windows, Python 3.8 or Higher, Python IDLE

THEORY:
Alpha-Beta Pruning is an optimization technique for the Minimax algorithm used in two-player games such as Chess, Tic-Tac-Toe, and Checkers.
It reduces the number of nodes that need to be evaluated without changing the final result.
• Alpha (α): Best value that the MAX player can guarantee so far.
• Beta (β): Best value that the MIN player can guarantee so far.
• When α ≥ β, the remaining branches are pruned because they cannot affect the final decision. This is called pruning.

MAX player: Tries to maximize the score.
MIN player: Tries to minimize the score.

ALGORITHM:
1. Start from the root node.
2. Set alpha = -∞ and beta = +∞.
3. If the node is a leaf node, return its value.
4. For a MAX node:
   o Find the maximum value.
   o Update alpha.
5. For a MIN node:
   o Find the minimum value.
   o Update beta.
6. If alpha >= beta, stop exploring that branch.
7. Return the optimal value

CONCLUSION:
Thus, the Alpha-Beta Pruning algorithm was successfully implemented.
