EXPERIMENT NO.9
======================================================================

AIM:
Write a program to simulate a fuzzy control system

RESOURCE REQUIREMENTS:
Google Colab

THEORY:
A Fuzzy Control System uses fuzzy logic to make decisions based on approximate values rather than only true/false conditions.

The main steps are:
1. Fuzzification – Converts the temperature into fuzzy values such as low and high.
2. Rule Evaluation – Applies fuzzy rules.
3. Defuzzification – Converts the fuzzy result into a numerical fan speed.

Example rules:
• If temperature is low, fan speed is low.
• If temperature is high, fan speed is high.

CONCLUSION:
The fuzzy control system successfully simulated fan-speed control according to temperature.
