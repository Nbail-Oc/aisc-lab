EXPERIMENT NO-3
======================================================================

AIM:
To implement uninformed search technique using Breadth-First Search (BFS) Algorithm to solve the Water Jug Problem

RESOURCE REQUIREMENTS:
Windows, Python 3.8 or Higher, Google Colab

THEORY:
An Uninformed Search (also called Blind Search) is a search strategy that does not use any domain-specific knowledge or heuristics to evaluate states. It explores the search space systematically by traversing nodes solely based on graph/tree structure, without knowing how close a state is to the goal.

Breadth-First Search (BFS) is a classic uninformed search algorithm. It explores the state space layer by layer (level-order traversal):
• Uses a First-In, First-Out (FIFO) queue to store nodes to be visited.
• Guarantees finding the shortest path (fewest number of state transitions) to the goal state in an unweighted state space.

Water Jug Problem
Two water jugs are given:
• Jug A = 4 liters
• Jug B = 3 liters
Initially, both jugs are empty. Allowed operations:
• Fill Jug A
• Fill Jug B
• Empty Jug A
• Empty Jug B
• Pour water from Jug A to Jug B
• Pour water from Jug B to Jug A

Goal: Measure exactly 2 liters in the 4-liter jug.
Initial State: (0,0)
Goal State: (2,x) where x can be any quantity.

ALGORITHM:
1. Start from the initial state (0,0).
2. Initialize a FIFO queue with (initial_state, path) and a set to keep track of visited states.
3. Dequeue the front state from the queue.
4. If the current state matches the goal condition (Jug A == 2), return the solution path.
5. Generate all possible neighboring states using the allowed operations.
6. For each unvisited neighbor, append it to the queue along with the updated path, and mark it as visited.
7. Repeat until the goal state is reached.
8. Print the solution path.

CONCLUSION:
The Water Jug Problem was successfully solved using the Breadth-First Search (BFS) uninformed search algorithm.
