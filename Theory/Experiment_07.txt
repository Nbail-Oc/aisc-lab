======================================================================

AIM:
To implement an Associative Memory Network for a given problem statement.

RESOURCE REQUIREMENTS:
Google Colab, NumPy library

THEORY:
An Associative Memory Network is a type of neural network used to store and retrieve patterns. It can recall a stored pattern even when the input pattern is incomplete or contains some noise.

A common model of associative memory is the Hopfield Network. It uses interconnected neurons and stores patterns using a weight matrix. During recall, the network updates the input pattern until it reaches a stable state corresponding to a stored pattern.

Associative memory is mainly used in pattern recognition, image restoration, error correction, and pattern retrieval.

ALGORITHM:
1. Start the program.
2. Import the NumPy library.
3. Define the patterns to be stored.
4. Calculate the weight matrix.
5. Give a noisy input pattern.
6. Compare the input with the stored pattern using the weight matrix.
7. Update the input pattern.
8. Repeat the process until the pattern becomes stable.
9. Display the recalled pattern.
10. Stop the program.

CONCLUSION:
Thus, the Associative Memory Network successfully recalled the original stored pattern from a noisy input pattern.
