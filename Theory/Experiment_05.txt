======================================================================

AIM:
To implement Supervised Learning using Linear Regression in Python to predict continuous outcome values based on input features.

RESOURCE REQUIREMENTS:
Windows, Python 3.8 or Higher, Google Colab.

THEORY:
Supervised Learning is a subcategory of machine learning where the model is trained using labeled datasets, meaning the input data is already paired with correct output labels. The goal is for the model to learn a mapping function from input variables (x) to target outputs (y).

Linear Regression is a fundamental supervised algorithm used to predict continuous quantitative values. It assumes a linear relationship between input x and output y:

y = m.x + b

Where:
y: Predicted Target Output
x: Input Feature Value
m: Weight/Slope parameter
b: Bias/Intercept parameter

During training, the model uses an optimization algorithm called Gradient Descent to minimize the Mean Squared Error (MSE) between actual and predicted target values by iteratively adjusting m and b.

CONCLUSION:
Supervised Learning via Linear Regression was successfully implemented in Python, and predictions were generated on unseen data.
