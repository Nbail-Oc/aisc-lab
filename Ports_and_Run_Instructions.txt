CN LAB: CODE AND PORTS
======================

EXPERIMENT 8 - TCP client/server
Port: 12345 (TCP)
Files:
  Code/Experiment_08_TCP_Server.py
  Code/Experiment_08_TCP_Client.py

Run the server first with F5 in IDLE. In a second IDLE window, run the
client with F5. The teacher's localhost setup uses both programs on the
same computer.

EXPERIMENT 9 - UDP file transfer
Port: 5000 (UDP)
Files:
  Code/Experiment_09_UDP_Receiver.py
  Code/Experiment_09_UDP_Sender.py

Run the receiver first. On another computer, set SERVER_IP in the sender
to the receiver's IP address (find it with ipconfig), then run the sender
and enter the file path when asked. Both computers must be on the same
network, and the firewall must allow UDP port 5000.

Experiments 2-7 and 10 are command-line or network-simulator procedures in
the supplied PDFs; they do not use Python socket ports.
